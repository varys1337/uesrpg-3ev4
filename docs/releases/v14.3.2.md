This update includes the recent combat, magic, inventory, character creation,
and Core rules workflow changes. Some abilities now stop with instructions for
manual resolution when their costs, choices, or outcomes cannot yet be safely
automated.

The included Core compendiums are the existing compiled packs matched to their
authoring sources. Additional compendium corrections remain in a separate
source-only staging copy and are not included in this release. The full Core
feature review is still in progress.

The release passed static validation and pack-parity checks. The current
Foundry scenarios have not been run; back up your world before updating.

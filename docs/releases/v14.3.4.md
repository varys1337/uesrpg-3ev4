# v14.3.4: update comparison compatibility

This emergency compatibility release uses the Foundry manifest version `v14.3.4` to address leading-`v` version comparisons that could replace the fork with upstream RC.81. The npm package version remains `14.3.4`.

This is a temporary workaround. The upstream Foundry package catalogue entry still shares this system's ID; this release does not resolve that conflict or guarantee Foundry will retain the fork's update manifest. Back up your worlds and installed system before changing versions, and verify the installed system and its update source after updating.

Foundry 14.369's version comparison does not regard a later numeric version such as `14.3.5` as newer than `v14.3.4`. Future releases need an explicitly validated versioning transition; the ordinary numeric release path cannot be assumed to update this release automatically.

No gameplay mechanics, data schemas, or user-facing system functionality were intentionally changed. Foundry compatibility remains minimum 14.368, verified 14.368, and maximum 14.

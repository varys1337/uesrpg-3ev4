## Changes

- Updates Combat Senses initiative choices, dynamic-round handling, and combat initiative updates.
- Carries Hyper Awareness choices through additional skill and opposed-roll workflows, and improves damage-result presentation.
- Applies matching typed weakness after mitigation, once per damage type in an attack, including spell damage with multiple components. Recognizable legacy weakness resistance effects are handled without counting both representations.
- Resolves numeric Active Effect expressions using their actor, item, and effect context.
- Preserves staged character-generation purchase requests and applies existing spell-component penalties for active conditions.
- Synchronizes the release manifest, archive URL, and package version for this fork.

## Known limitations

- These changes have not been verified in a running Foundry world. The talent and Active Effect audits remain incomplete; their inventories identify unresolved behavior.
- Weakness penalties for non-damaging tests and some source-dependent weaknesses remain unresolved. Older or customized effects without identifiable provenance may need GM review.
- Ordinary spells still use the existing caster-side tracking effects; target-owned spell tracking has not been implemented. Existing active casts have not been migrated.
- A reported GM-only character-generation rejection remains under investigation. The system shares its package ID with the upstream system, so automatic update selection cannot be guaranteed.

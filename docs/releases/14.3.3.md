# 14.3.3: update source and versioning

This release uses the numeric tag and system version `14.3.3`. The stable
update manifest is:

https://github.com/varys1337/uesrpg-3ev4/releases/latest/download/system.json

If an older installation does not find this release, or follows the original
project instead, back up your Foundry user data and install this fork using the
manifest URL above in Foundry's game-system installer. If Foundry reports that
the system is already installed and will not replace it, back up first, then
uninstall only the system package and reinstall it from that manifest; do not
delete worlds or user data. The fork retains the system ID `uesrpg-3ev4`, so
existing worlds continue to refer to that ID.

When Foundry offers to switch the manifest to the original project's listing,
decline the switch to keep following this fork. The original official listing
shares the same system ID, so this release cannot eliminate that prompt or
guarantee automatic update detection in every installation. Earlier releases
also used `v`-prefixed system versions, which may affect version comparison.
The update and recovery procedure has not been verified in a live Foundry session.

The Core packs are the existing compiled packs matched to their authoring
sources. The separately staged, unverified compendium corrections are not
included. The broader Core feature review remains in progress.
